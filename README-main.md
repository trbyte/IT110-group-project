# 💱 IT110 Group Project – Currency Converter Web App

A simple, static web project for **IT110 – Introduction to Computing** built with **HTML, CSS, and JavaScript**.  
This README provides an overview of the project, how to run it locally, its structure, and contribution guidelines for the team.

---

## 📝 Description
The **Currency Converter Web Application** is a web-based tool that allows users to easily convert between multiple international currencies in real time.  
It integrates a public API to fetch live exchange rate data, ensuring accurate and up-to-date conversions.  
The project demonstrates teamwork, use of APIs, responsive web design, and version control through Git and GitHub.

---

## 🎯 Objectives
- To develop a web application that performs real-time currency conversion.  
- To utilize a public API for retrieving current exchange rates.  
- To design a responsive and user-friendly interface.  
- To practice collaboration using Git and GitHub for version control.

---

## 🧩 Key Features
- **Real-Time Exchange Rates** – Fetches up-to-date exchange rates from a public API.  
- **Multi-Currency Support** – Allows conversion across a variety of currencies.  
- **Bidirectional Conversion** – Supports quick swapping between base and target currencies.  
- **Responsive Interface** – Adapts smoothly to desktop, tablet, and mobile devices.
